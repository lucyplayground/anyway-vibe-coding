# 튜토리얼 03

## 실습 제목
Tutorial 3 AI에 기반한 컬러 팔레트 생성기 만들기

## 목표
단순한 키워드로 조화로운 색상 조합을 제안하는 도구를 만드세요.

- 테마 단어(예: 석양 등)를 입력해 다섯 가지 색상을 받기
- 한 번의 클릭으로 모든 헥스 코드(hex code)를 복사하기
- 같은 단어에 대한 새로운 팔레트를 얻기 위해 셔플(shuffle)하기
- 실시간 블록으로 색상을 미리 보기

## 실행 방법

`app/index.html`을 웹 브라우저로 열면 됩니다. 별도의 설치나 빌드 과정은 없습니다.

현재는 테마 단어 입력 상자, **생성**·**셔플** 버튼, 빈 색상 표시 영역을 갖춘 기본 화면입니다. 두 버튼은 나란히 표시되며, 작은 화면에서는 입력 상자 아래에 배치됩니다. 색상 생성과 셔플 동작은 아직 연결하지 않았습니다.
