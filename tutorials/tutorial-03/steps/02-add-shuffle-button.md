# 02. 셔플 버튼 추가

- 상태: 완료

## 사용자 프롬프트 원문
```text
'생성' 버튼 옆에 '셔플' 버튼을 추가해 줘.
```

## AI 응답 (요약)
‘생성’ 버튼 오른쪽에 ‘셔플’ 버튼을 추가했다. 흰색 배경과 보라색 글자로 구분하고, 모바일에서도 두 버튼을 나란히 배치했다. 이번 단계는 버튼 UI만 추가했으며 셔플 동작은 아직 연결하지 않았다.

## 생성·변경 내용
- `app/index.html`: ‘생성’·‘셔플’ 버튼을 버튼 그룹에 배치.
- `app/style.css`: 버튼 그룹, 셔플 버튼의 기본·호버·누름 스타일 및 모바일 버튼 너비 지정.
- `README.md`: 현재 구현 범위에 셔플 버튼 추가.
- `steps/02-add-shuffle-button.md`: 두 번째 개발 요청과 처리 내용 기록.
