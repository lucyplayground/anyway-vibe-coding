# 02. 셔플 버튼 추가

- 상태: 완료

## 사용자 프롬프트 원문
```text
'생성' 버튼 옆에 '셔플' 버튼도 추가해 줘.
```

## AI 응답 (요약)
‘생성’ 버튼 옆에 ‘셔플’ 버튼을 추가했다. 셔플 버튼은 테두리 스타일로 구분하고, 작은 화면에서도 두 버튼이 나란히 표시되도록 배치했다. 이번 단계에서는 버튼 UI만 추가했으며 셔플 동작은 아직 연결하지 않았다.

## 생성·변경 내용
- `app/index.html`: 생성·셔플 버튼을 나란히 묶고 셔플 버튼 추가.
- `app/style.css`: 버튼 그룹 배치, 셔플 버튼 스타일, 작은 화면에서의 버튼 너비 조정.
- `README.md`: 셔플 버튼과 현재 구현 범위 안내 갱신.
- `steps/02-add-shuffle-button.md`: 사용자 요청 원문과 처리 내용 기록.
