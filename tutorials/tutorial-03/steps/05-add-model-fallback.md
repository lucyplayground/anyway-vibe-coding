# 05. 재시도 후 대체 모델 전환

- 상태: 완료

## 사용자 프롬프트 원문
```text
gemini 응답 처리 지연 문제는 3번의 요청을 보내고도 실패한다면 다른 모델을 사용할 수 있도로 코드를 수정해줘
```

## AI 응답 (요약)
기본 모델에 최대 3번 요청하고, 3번 모두 일시적 오류로 실패하면 대체 모델로 자동 전환하도록 수정했다. 재시도 사이에는 약 1초, 2초씩 늘어나는 대기(지수 백오프)와 약간의 무작위 지연을 둔다. 재시도 대상은 503·504·429·500·502, 연결 실패·응답 지연, 잘못된 색상 응답이다. 400·401·403은 재시도해도 해결되지 않으므로 바로 안내하고, 404(모델 없음)는 바로 대체 모델로 넘어간다. 대체 모델은 `docs/research.md`에서 실제로 동작을 확인한 `gemini-3.5-flash-lite`를 기본값으로 하고 `GEMINI_FALLBACK_MODEL`로 바꿀 수 있다. 한 번의 요청 제한을 60초에서 20초로 줄여 전체 시도가 약 83초 안에 끝나게 하고, 브라우저 제한은 100초로 늘렸다. 대체 모델로 생성하면 화면에 모델 이름을 알리고, 서버 터미널에 재시도·전환 기록을 남긴다. 테스트는 가짜 키와 모의 응답만 사용했으며 `.env`는 읽지 않았다. 실제 키로 확인하는 작업은 사용자가 직접 진행한다.

## 생성·변경 내용
- `app/gemini.mjs`: 단일 요청 함수 분리, 재시도 가능 오류 구분, 기본 모델 3회 재시도·백오프 후 대체 모델 전환, 요청당 20초 제한, 사용 모델과 대체 여부 반환.
- `app/server.mjs`: `GEMINI_FALLBACK_MODEL` 설정 전달, 재시도 기록을 터미널에 출력, 응답에 `model`·`fallback` 포함.
- `app/app.js`: 브라우저 대기 시간 100초로 조정, 로딩 안내 문구 보완, 대체 모델 사용 시 안내 표시.
- `app/.env.example`: `GEMINI_FALLBACK_MODEL` 예시 추가.
- `app/tests/palette.test.mjs`: 반환 형식 변경 반영, 재시도 성공·대체 모델 전환·모두 실패·404 즉시 전환·인증 오류 미재시도·동일 모델 중복 방지 검증 추가.
- `app/tests/ui.test.mjs`: 대체 모델 안내 표시 검증 추가.
- `README.md`: 재시도와 대체 모델 동작, 설정, 대기 시간 안내 추가.
- `steps/05-add-model-fallback.md`: 개발 요청 원문과 변경 내용 기록.
