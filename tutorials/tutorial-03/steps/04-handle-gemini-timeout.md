# 04. Gemini 응답 지연 처리

- 상태: 일부 완료

## 사용자 프롬프트 원문
```text
응답이 오래 걸려서 다시 시도해달래..
```

## AI 응답 (요약)
공식 추론 설정 문서에 따라 색상 생성의 추론 수준을 `low`로 낮추고 서버 제한을 60초, 브라우저 제한을 75초로 조정했다. 응답 본문을 읽는 중의 시간 초과도 별도로 처리하며, Gemini 서비스 혼잡과 서버 시간 초과 안내를 구분했다. 실행 중인 로컬 서버에 변경을 반영했다. 외부 서비스 오류가 남아 있어 실제 색상 생성 성공까지는 해결되지 않았다. 사용자의 실제 호출 요청에 따라 서버가 키를 내부적으로 사용하는 방식으로 진행했으며 키 파일 내용을 열거나 출력하지 않았다.

참고 문서: https://ai.google.dev/gemini-api/docs/thinking

## 생성·변경 내용
- `app/gemini.mjs`: 낮은 추론 수준, 요청 제한 조정, 응답 본문 시간 초과와 503·504 오류 구분.
- `app/app.js`: 브라우저 요청 제한을 서버보다 길게 조정.
- `app/tests/palette.test.mjs`: 추론 설정, 외부 서비스 오류 및 응답 본문 시간 초과에 대한 회귀 검증 추가.
- `README.md`: 추론 설정, 대기 시간과 혼잡 오류 안내 보완.
- `steps/04-handle-gemini-timeout.md`: 문제 해결 요청과 수정 내용 기록.
