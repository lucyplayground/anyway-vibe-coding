# 01. 기본 웹 페이지 만들기

- 상태: 완료

## 사용자 프롬프트 원문
```text
단어를 입력할 수 있는 상자, '생성'버튼, 그리고 색상이 표시될 빈 영역이 있는 간단한 웹 페이지 만들어 줘.
```

## AI 응답 (요약)
단어 입력 상자, ‘생성’ 버튼, 색상을 표시할 빈 영역으로 구성된 기본 웹 페이지를 만들었다. 작은 화면에서는 입력 상자와 버튼을 세로로 배치한다. 이번 단계는 화면 구성만 구현했으며 색상 생성 기능은 아직 연결하지 않았다. `app/index.html`을 브라우저에서 열어 사용할 수 있다.

## 생성·변경 내용
- `app/index.html`: 한국어 페이지 제목, 레이블이 있는 단어 입력 상자, ‘생성’ 버튼, 빈 색상 표시 영역 생성.
- `app/style.css`: 페이지 색상과 간격, 입력·버튼 스타일, 키보드 포커스 표시 및 모바일 레이아웃 작성.
- `README.md`: 실제 파일 구성에 맞는 실행 방법과 현재 구현 범위 추가.
- `steps/01-create-page.md`: 처음부터 다시 시작하는 실습의 첫 개발 요청과 처리 내용 기록.
