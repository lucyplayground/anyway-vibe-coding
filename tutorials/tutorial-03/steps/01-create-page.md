# 01. 기본 페이지 생성

- 상태: 완료

## 사용자 프롬프트 원문
```text
단어를 입력할 수 있는 상자, '생성' 버튼, 그리고 색상이 표시될 빈 영역이 있는 간단한 웹 페이지를 만들어 줘.
```

## AI 응답 (요약)
단어 입력 상자, ‘생성’ 버튼, 빈 색상 표시 영역을 갖춘 기본 웹 페이지를 만들었다. 작은 화면에서는 입력 상자와 버튼이 세로로 배치된다. `app/index.html`을 브라우저로 열어 사용할 수 있으며, 이번 단계에서는 색상 생성 동작을 연결하지 않았다.

## 생성·변경 내용
- `app/index.html`: 한국어 페이지 제목, 테마 단어 입력 상자, 생성 버튼, 색상 표시 영역 추가.
- `app/style.css`: 화면 스타일, 키보드 초점 표시, 작은 화면 배치 추가.
- `README.md`: 설치 없이 HTML 파일을 여는 실행 방법과 현재 구현 범위 안내.
- `steps/01-create-page.md`: 사용자 요청 원문과 처리 내용 기록.
