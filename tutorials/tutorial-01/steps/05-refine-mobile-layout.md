# 05. 모바일 목록 스타일 다듬기

- 상태: 완료

## 사용자 프롬프트 원문
```text
할 일 목록이 휴대폰 화면에 깔끔하게 보이도록 - 간격이 적당하고, 텍스트가 읽기 쉽고, 완료된 작업은 흐리게 - 만들어 줘.
```

## AI 응답 (요약)
휴대폰에서 목록을 읽고 누르기 편하도록 간격과 줄 높이를 조정했다. 완료 항목은 연한 배경에 회색 글자로 표시하고, 체크 표시와 취소선으로 구분할 수 있게 했다.

## 생성·변경 내용
- `app/index.html`의 CSS에서 입력 영역과 목록 사이의 간격, 항목 사이의 간격, 글자 줄 높이를 조정했다.
- 입력란과 버튼의 최소 높이를 48px로 늘리고 완료 항목에 연한 배경과 회색 글자를 적용했다.
