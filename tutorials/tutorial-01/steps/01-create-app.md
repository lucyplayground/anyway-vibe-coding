# 01. 할 일 목록 페이지 만들기

- 상태: 완료

## 사용자 프롬프트 원문
```text
휴대폰에서 사용할 할 일 목록을 위한 간단한 웹 페이지를 만들어 줘. 목록을 위한 공간과 '추가' 버튼 및 '삭제'버튼을 추가해 줘.
```

## AI 응답 (요약)
브라우저에서 바로 열 수 있는 HTML 파일 하나로 할 일 목록을 만들었다. 할 일을 입력하고 **추가**를 누르면 목록에 표시되며, 각 항목의 **삭제** 버튼으로 지울 수 있다. 휴대폰에서 누르기 쉬운 크기로 버튼을 배치했다.

## 생성·변경 내용
- `app/index.html`에 모바일 화면용 레이아웃, 할 일 입력과 목록, 추가·삭제 기능을 구현했다.
- `README.md`에 브라우저에서 페이지를 여는 방법과 사용법을 추가했다.
