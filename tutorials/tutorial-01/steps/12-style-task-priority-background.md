# 12. 우선순위를 할 일 배경색으로 표시

- 상태: 완료

## 사용자 프롬프트 원문
```text
마지막으로 우선순위에 대한 태그로 우선순위 정보를 표시하지 말고 할 일 목록 바탕화면? 으로 표시를 해줘

그리고 체크박스에는 배경이 감싸지지 않도록 해줘
할 일 부분만 편집 삭제 버튼 높이에 맞추고 배경에 감싸지도록 스타일 변경해 줘.
```

## AI 응답 (요약)
우선순위 배지 대신 할 일 제목의 배경색으로 우선순위를 구분한다. 체크박스는 색상 영역 밖에 두고, 제목 배경과 편집·삭제 버튼은 한 줄에서 같은 높이로 맞췄다.

## 생성·변경 내용
- `app/index.html`에서 우선순위 배지를 제거하고 제목 배경에 우선순위 색상을 적용했다. 화면 읽기 프로그램에서도 우선순위를 확인할 수 있게 했다.
- `README.md`에 우선순위별 배경색을 안내했다.
