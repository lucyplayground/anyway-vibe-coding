# 11. 모바일 우선순위와 정렬 UI 다듬기

- 상태: 완료

## 사용자 프롬프트 원문
```text
UI가 너무 밤티인데...
차라리등록할 때, 우선순위를 정하고 편집할 때, 우선순위를 수정할 수 있는 방향으로 수정해줘.
그리고 정렬순 select 박스라고 해야하나? 그것도 UI가 별로야. 깔끔하게 모바일에 맞춘 UIUX로 수정해줘.
```

## AI 응답 (요약)
등록하거나 편집할 때 우선순위를 고르고, 목록에는 지정한 우선순위만 배지로 표시한다. 목록 상단에서 등록순과 우선순위순을 버튼으로 전환할 수 있다.

## 생성·변경 내용
- `app/index.html`에서 목록의 우선순위 선택 상자를 제거하고, 등록·편집 폼에 터치용 선택 버튼을 추가했다.
- 정렬 드롭다운을 등록순·우선순위순 전환 버튼으로 바꾸고, 선택 상태와 키보드 포커스를 구분했다.
- `README.md`에 변경한 사용 흐름을 반영했다.
