# 09. 할 일 목록을 브라우저에 저장

- 상태: 완료

## 사용자 프롬프트 원문
```text
내가 등록한 할 일 목록이 새로고침해도 할 일이 사라지지 않도록 localStorage에 저장하는 기능을 구현해 줘.
```

## AI 응답 (요약)
할 일의 내용, 순서, 완료 상태를 브라우저의 localStorage에 저장한다. 추가·편집·완료 전환·삭제가 저장에 반영되며, 같은 페이지를 다시 열면 목록이 복원된다.

## 생성·변경 내용
- `app/index.html`에 목록 저장과 복원 로직을 추가하고, 브라우저 저장을 사용할 수 없을 때 안내를 표시하도록 했다.
- `README.md`에 자동 저장 및 복원 동작을 안내했다.
