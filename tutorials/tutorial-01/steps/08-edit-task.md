# 08. 할 일 편집 기능 추가

- 상태: 완료

## 사용자 프롬프트 원문
```text
등록된 할 일을 편집할 수 있는 기능을 구현해 줘.
사용자 경험을 최적화한 방향으로 만들어 줘.
```

## AI 응답 (요약)
등록한 할 일의 **편집**을 누르면 목록 안에서 기존 내용을 바로 수정할 수 있다. **저장**으로 반영하고 **취소**로 돌아갈 수 있다. 공백만 입력한 내용은 저장할 수 없고, 완료된 항목을 수정해도 완료 상태가 유지된다.

## 생성·변경 내용
- `app/index.html`에 항목별 편집 버튼과 저장·취소 입력 폼을 추가했다. 편집을 시작하면 입력란에 포커스를 두고, 편집을 닫으면 편집 버튼으로 포커스를 돌려준다.
- `README.md`에 등록한 할 일을 편집하는 방법을 추가했다.
