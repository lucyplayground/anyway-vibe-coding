# 튜토리얼 02

## 실습 제목
Tutorial 2 Chart.js로 인터랙티브 차트 대시보드 만들기

## 목표
사용자가 인터랙티브 차트 데이터를 시각화할 수 있는 반응형 대시보드를 만드세요.

- 막대 차트와 꺾은선 차트를 나란히 표시하기
- 개별 데이터세트를 켜고 끄기
- 실시간으로 차트에 새 데이터 스트리밍하기

## 실행 방법

`app/index.html`을 웹 브라우저로 열면 됩니다. 별도의 설치나 빌드 과정은 없습니다.

Chart.js 4.5.1을 jsDelivr CDN에서 불러오므로 인터넷 연결이 필요합니다.

현재는 월별 판매액을 막대 차트로, 1월부터 해당 월까지의 누적 판매액을 꺾은선 차트로 표시합니다. 넓은 화면에서는 두 차트가 나란히, 700px 이하 화면에서는 세로로 배치됩니다. 그 아래에는 시장 점유율 원형 차트가 표시됩니다.

각 차트의 **월별 판매 표시**, **누적 합계 표시**, **시장 점유율 표시** 체크박스로 데이터세트를 독립적으로 켜고 끌 수 있습니다. 처음에는 모든 데이터세트가 표시됩니다. 판매 차트의 범례를 클릭하면 체크 상태가 함께 바뀝니다. 표시를 꺼도 원본 데이터는 유지되며, 체크박스에 키보드 초점을 둔 뒤 Space 키로도 조작할 수 있습니다.

## 예시 데이터

실제 판매 수치가 제공되지 않아 1~6월 예시 데이터를 사용합니다. 단위는 만원입니다.

| 월 | 판매액 | 누적 합계 |
| --- | ---: | ---: |
| 1월 | 120 | 120 |
| 2월 | 150 | 270 |
| 3월 | 180 | 450 |
| 4월 | 140 | 590 |
| 5월 | 210 | 800 |
| 6월 | 240 | 1,040 |

`app/app.js`의 `salesData` 배열에서 월과 판매액을 수정하면, 페이지를 다시 열거나 새로고침할 때 두 차트와 누적 합계에 반영됩니다.

## 자동 데이터 갱신

차트가 로드되면 3초마다 다음 월의 예시 판매액(100~300만원 사이의 랜덤 정수)을 추가하고 두 차트를 함께 갱신합니다. 12월 다음에는 `2년차 1월`처럼 월을 구분합니다. 실제 서버에서 받는 데이터가 아닌 실습용 시뮬레이션입니다.

차트에는 최근 12개월을 표시하며, 누적 합계는 표시 범위에서 빠진 월도 포함해 처음부터 계속 합산합니다. 숨겨 둔 데이터세트도 새 데이터를 받고 체크 상태를 유지합니다. 다시 체크하면 최신 데이터가 표시됩니다.

상단의 **실시간 업데이트** 토글을 끄면 데이터 추가가 일시 중지됩니다. 다시 켜면 현재 데이터에 이어서 3초 후부터 갱신합니다. 중지 중에도 데이터세트 표시 체크박스는 사용할 수 있으며, 중지한 동안의 데이터를 한꺼번에 추가하지 않습니다. 토글에 키보드 초점을 둔 뒤 Space 키로도 조작할 수 있습니다.

새로고침하면 초기 1~6월 데이터에서 다시 시작합니다. `app/app.js`의 `streamIntervalMs`로 갱신 간격을, `maxVisibleMonths`로 표시할 월 수를 조정할 수 있습니다.

## 시장 점유율 원형 차트

실제 통계가 아닌 고정 예시 데이터로 A사 40%, B사 30%, C사 20%, 기타 10%를 표시합니다. 범례와 마우스 오버 안내에 백분율을 표시하며, 범례를 클릭하면 해당 조각만 숨기거나 다시 표시할 수 있습니다. **시장 점유율 표시** 체크박스는 원형 차트의 전체 데이터세트를 제어합니다.

`app/app.js`의 `marketShareData` 배열에서 이름·점유율·색상을 수정할 수 있습니다. 점유율의 합계는 100%로 맞춰 주세요. 판매 데이터 자동 갱신 토글은 월별 판매와 누적 합계에 적용되며, 고정 예시 점유율은 자동 변경되지 않습니다.
