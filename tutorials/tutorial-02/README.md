# 튜토리얼 02

## 실습 제목
Tutorial 2 Chart.js로 인터랙티브 차트 대시보드 만들기

## 목표
사용자가 인터랙티브 차트 데이터를 시각화할 수 있는 반응형 대시보드를 만드세요.

- 막대 차트와 꺾은선 차트를 나란히 표시하기
- 개별 데이터세트를 켜고 끄기
- 실시간으로 차트에 새 데이터 스트리밍하기

## 실행 방법

`app/index.html`을 웹 브라우저로 열면 됩니다. 별도의 설치나 빌드 과정은 없습니다.

Chart.js 4.5.1을 jsDelivr CDN에서 불러오므로 인터넷 연결이 필요합니다.

현재는 월별 판매액을 막대 차트로, 1월부터 해당 월까지의 누적 판매액을 꺾은선 차트로 표시합니다. 넓은 화면에서는 나란히, 700px 이하 화면에서는 세로로 배치됩니다.

각 차트의 **월별 판매 표시**, **누적 합계 표시** 체크박스로 데이터세트를 독립적으로 켜고 끌 수 있습니다. 처음에는 두 데이터세트가 모두 표시됩니다. 범례를 클릭해도 체크 상태가 함께 바뀌며, 표시를 꺼도 원본 판매액과 누적 합계는 유지됩니다. 체크박스에 키보드 초점을 둔 뒤 Space 키로도 조작할 수 있습니다.

## 예시 데이터

실제 판매 수치가 제공되지 않아 1~6월 예시 데이터를 사용합니다. 단위는 만원입니다.

| 월 | 판매액 | 누적 합계 |
| --- | ---: | ---: |
| 1월 | 120 | 120 |
| 2월 | 150 | 270 |
| 3월 | 180 | 450 |
| 4월 | 140 | 590 |
| 5월 | 210 | 800 |
| 6월 | 240 | 1,040 |

`app/app.js`의 `salesData` 배열에서 월과 판매액을 수정하면, 페이지를 다시 열거나 새로고침할 때 두 차트와 누적 합계에 반영됩니다.
