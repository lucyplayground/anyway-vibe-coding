# 07. 노트북·휴대폰 차트 배치 확인

- 상태: 완료

## 사용자 프롬프트 원문
```text
CSS를 사용해서 노트북에서는 두 차트가 나란히 보이지만 휴대폰에서는 위아래로 쌓이도록 해 줘.
```

## AI 응답 (요약)
기존 CSS에 요청한 반응형 배치가 이미 구현되어 있어 해당 규칙을 그대로 사용한다. `.chart-grid`는 기본적으로 두 열이며, `@media (max-width: 700px)`에서 한 열로 바뀐다. 따라서 노트북에서는 두 차트가 나란히, 휴대폰에서는 위아래로 표시된다. 앱 코드를 추가로 수정하지 않았다.

## 생성·변경 내용
- `steps/07-responsive-layout.md`: 사용자 요청 원문과 기존 반응형 CSS의 적용 내용을 기록.
- `app/styles.css`: 요청한 2열·1열 배치가 이미 구현되어 있어 변경 없음.
- `README.md`: 기존 문서에 700px 기준의 배치 설명이 있어 변경 없음.
