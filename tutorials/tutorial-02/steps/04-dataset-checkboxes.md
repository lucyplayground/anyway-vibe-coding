# 04. 데이터세트별 체크박스 추가

- 상태: 완료

## 사용자 프롬프트 원문
```text
단일 버튼을 각 데이터세트에 대한 체크박스로 바꿔줘
```

## AI 응답 (요약)
막대 표시 전환 버튼을 `월별 판매 표시`와 `누적 합계 표시` 체크박스로 교체했다. 각 체크박스로 해당 차트의 데이터세트를 독립적으로 표시하거나 숨길 수 있으며, 범례 클릭 시에도 체크 상태가 동기화된다. 초기에는 두 항목이 모두 선택되고, 차트 초기화 후 체크박스가 활성화된다. 원본 데이터와 누적 계산을 보존하며 키보드 Space 키로도 조작할 수 있다.

## 생성·변경 내용
- `app/index.html`: 단일 버튼을 제거하고 각 차트에 레이블과 연결된 체크박스 추가.
- `app/app.js`: 데이터세트별 체크박스 연결, 독립 표시 전환, 범례 클릭과 체크 상태 동기화, 접근성 설명 갱신 추가.
- `app/styles.css`: 버튼 전용 스타일을 체크박스 레이블·포커스·비활성화 스타일로 교체.
- `README.md`: 체크박스 사용 방법과 기본 선택 상태, 키보드 조작 안내로 갱신.
