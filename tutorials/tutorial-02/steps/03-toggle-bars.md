# 03. 막대 표시 전환 버튼 추가

- 상태: 완료

## 사용자 프롬프트 원문
```text
클릭하면 막대를 숨기거나 보여 주는 버튼을 만들어 줘.
```

## AI 응답 (요약)
월별 판매 차트에 막대를 숨기거나 다시 표시하는 버튼을 추가했다. 버튼 문구는 현재 상태에 맞춰 `막대 숨기기`와 `막대 보여 주기`로 바뀌며, 범례를 클릭해 상태를 바꿔도 동기화된다. 누적 합계 차트와 판매 데이터는 유지된다. 버튼은 키보드로도 조작할 수 있으며, Chart.js 초기화가 완료되어야 활성화된다.

## 생성·변경 내용
- `app/index.html`: 월별 판매 차트 제목 옆에 막대 표시 전환 버튼 추가.
- `app/app.js`: Chart.js 데이터세트 표시 상태 전환, 버튼 문구 및 접근성 설명 갱신, 범례 클릭과 버튼 상태 동기화 추가.
- `app/styles.css`: 버튼 배치·색상·포커스·비활성화 스타일 추가.
- `README.md`: 버튼과 범례를 이용한 막대 표시 전환 방법 추가.
