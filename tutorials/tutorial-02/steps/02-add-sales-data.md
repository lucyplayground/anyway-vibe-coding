# 02. 월별 판매와 누적 합계 표시

- 상태: 완료

## 사용자 프롬프트 원문
```text
월별 판매를 막대로, 누적 합계를 선으로 보여 주는 코드를 추가해 줘.
```

## AI 응답 (요약)
월별 판매액을 막대 차트로, 같은 판매액에서 계산한 누적 합계를 꺾은선 차트로 표시하도록 구현했다. 실제 판매 수치가 제공되지 않아 1~6월 예시 데이터(단위: 만원)를 사용하고 화면과 README에 명시했다. `app/app.js`의 `salesData` 배열을 수정한 뒤 새로고침하면 두 차트에 반영된다.

## 생성·변경 내용
- `app/app.js`: 월별 예시 판매액과 누적 합계 계산, 두 차트의 데이터세트·색상·단위 설정, 월별 수치를 포함한 접근성 설명 추가.
- `app/index.html`: 차트 제목을 월별 판매·누적 합계로 변경하고, 예시 데이터·단위 안내 추가 및 빈 데이터 문구 제거.
- `app/styles.css`: 사용하지 않는 빈 데이터 안내 스타일 제거.
- `README.md`: 현재 표시 내용, 월별 판매액·누적 합계 표, 데이터 수정 방법 추가.
