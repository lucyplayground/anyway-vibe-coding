# 06. 실시간 업데이트 일시 중지 토글 추가

- 상태: 완료

## 사용자 프롬프트 원문
```text
실시간 업데잍를 일시 중지하거나 재시작하는 토클 추가해줘.
```

## AI 응답 (요약)
상단에 `실시간 업데이트` 토글을 추가했다. 토글을 끄면 현재 판매 데이터와 누적 합계를 유지하며 자동 추가를 멈추고, 다시 켜면 3초 후부터 이어서 갱신한다. 반복 조작 시 기존 타이머를 해제해 중복 실행을 방지한다. 데이터세트 체크 상태는 유지되며, 중지 중에도 표시 여부를 바꿀 수 있다. 토글은 키보드 Space 키로도 조작할 수 있다.

## 생성·변경 내용
- `app/index.html`: 실시간 업데이트 스위치와 상태 안내를 묶은 제어 영역 추가.
- `app/styles.css`: 토글의 켜짐·꺼짐·포커스·비활성화 상태와 모바일 줄바꿈 배치 추가.
- `app/app.js`: 갱신 실행 상태 관리, 토글에 따른 타이머 해제·재시작, 상태 안내 갱신, 차트 로딩 실패 시 토글 비활성화 처리 추가.
- `README.md`: 일시 중지·재시작 동작과 키보드 조작 방법 추가.
