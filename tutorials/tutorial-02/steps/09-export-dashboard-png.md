# 09. 대시보드 PNG 내보내기 추가

- 상태: 완료

## 사용자 프롬프트 원문
```text
대시보드를 PNG 이미지로 내보내는 기능 추가해 줘.
```

## AI 응답 (요약)
상단에 `PNG로 내보내기` 버튼을 추가했다. 제목·설명과 세 차트를 현재 노트북·휴대폰 배치에 맞춰 하나의 PNG로 다운로드한다. 스크롤 아래의 차트와 현재 데이터 숨김 상태도 반영하며, 조작 UI는 이미지에서 제외한다. 이미지 생성 중에는 데이터 추가와 조작을 잠시 멈추고 끝나면 이전 자동 갱신·일시 중지 상태로 복귀한다. 생성 실패 시 안내하고 다시 시도할 수 있다.

## 생성·변경 내용
- `app/index.html`: html2canvas 1.4.1 CDN 로딩, PNG 내보내기 버튼·상태 안내, 이미지에서 제외할 조작 UI 표시 추가.
- `app/app.js`: 대시보드 전체 캡처와 PNG 다운로드, 차트 애니메이션·툴팁 정리, 캡처 중 데이터 고정과 조작 잠금 및 완료·실패 후 상태 복구 추가.
- `app/app.js`: 복제 문서에서 현재 차트 카드 위치 유지, 조작 UI·숨겨진 안내·캔버스 대체 텍스트를 제거해 이미지에 겹쳐 나오지 않도록 처리.
- `app/styles.css`: 내보내기 버튼의 기본·호버·포커스·비활성화 상태와 캡처 중 차트 조작 제한 스타일 추가.
- `README.md`: 내보내기 의존성과 PNG 저장 범위·숨김 상태 반영·일시 중지 및 복구 동작 안내 추가.
