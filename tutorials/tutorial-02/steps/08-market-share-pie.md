# 08. 시장 점유율 원형 차트 추가

- 상태: 완료

## 사용자 프롬프트 원문
```text
시장 점유율을 보여주는 원형 차트를 추가해 줘.
```

## AI 응답 (요약)
판매 차트 아래에 시장 점유율 원형 차트를 추가했다. 실제 수치가 제공되지 않아 A사 40%, B사 30%, C사 20%, 기타 10%의 고정 예시를 사용하며, 실제 통계가 아님을 표시했다. 범례와 마우스 오버 안내에 백분율을 표시하고, 시장 점유율 체크박스로 전체 데이터세트를, 범례로 개별 조각을 숨기거나 표시할 수 있다. 기존 판매 데이터 자동 갱신은 판매 차트에 적용되고 예시 점유율은 고정으로 유지된다.

## 생성·변경 내용
- `app/app.js`: 시장 점유율 예시 데이터, Chart.js 원형 차트, 백분율 범례·툴팁, 전체 데이터세트와 개별 조각 표시 전환 및 접근성 설명 추가.
- `app/index.html`: 시장 점유율 카드와 체크박스·캔버스·예시 안내 추가, 페이지 설명 보완.
- `app/styles.css`: 판매 차트 아래의 전체 너비 카드와 화면 크기에 맞는 원형 차트 컨테이너 스타일 추가.
- `README.md`: 원형 차트의 배치, 점유율 예시, 표시 전환과 데이터 수정 방법 추가.
