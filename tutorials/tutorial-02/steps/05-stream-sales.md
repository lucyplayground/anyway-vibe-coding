# 05. 랜덤 판매 데이터 스트리밍 추가

- 상태: 완료

## 사용자 프롬프트 원문
```text
몇 초마다 랜덤하게 판매 수치를 추가하고 두 차트 모두 최신 상태로 유지해 줘.
```

## AI 응답 (요약)
3초마다 다음 월의 랜덤 판매액(100~300만원)을 추가하고 월별 판매와 누적 합계 차트를 함께 갱신하도록 구현했다. 차트에는 최근 12개월을 표시하며, 누적 합계는 표시 범위에서 빠진 월도 포함해 계속 합산한다. 체크박스로 숨겨 둔 데이터세트도 최신 데이터를 받고 숨김 상태를 유지한다. 실제 판매 데이터가 아닌 실습용 예시임을 표시하고, 새로고침하면 초기 데이터에서 다시 시작한다.

## 생성·변경 내용
- `app/app.js`: 3초 주기의 랜덤 판매액 추가, 다음 월·연차 레이블 생성, 최근 12개월 표시 제한, 누적 합계와 두 차트의 동시 갱신 추가.
- `app/app.js`: 갱신 중 체크 상태 보존 및 접근성 설명 갱신, 페이지 이탈 시 타이머 해제와 뒤로 가기 복원 시 재시작 처리 추가.
- `app/index.html`: 랜덤 예시 데이터 안내와 자동 갱신 상태 표시 추가.
- `README.md`: 갱신 주기·판매액 범위·표시 기간·누적 방식·새로고침 동작과 설정값 안내 추가.
