# 01. 기본 차트 페이지 생성

- 상태: 완료

## 사용자 프롬프트 원문
```text
빈 차트 두 개가 나란히 있는 기본 웹 페이지를 만들어 줘. Chart.js 도 로드해 줘.
```

## AI 응답 (요약)
Chart.js 4.5.1을 CDN에서 불러오는 기본 웹 페이지를 만들었다. 데이터가 없는 막대 차트와 꺾은선 차트를 넓은 화면에서는 나란히, 700px 이하 화면에서는 세로로 배치한다. 별도의 설치나 빌드 없이 `app/index.html`을 브라우저에서 열 수 있으며, CDN 로딩에는 인터넷 연결이 필요하다.

## 생성·변경 내용
- `app/index.html`: 페이지 제목, 차트 영역 두 개, Chart.js 및 앱 스크립트 로딩, 접근성 설명과 로딩 실패 안내 추가.
- `app/styles.css`: 차트 카드와 반응형 2열·1열 레이아웃 추가.
- `app/app.js`: 데이터가 비어 있는 막대 차트와 꺾은선 차트 초기화.
- `README.md`: 실제 페이지 구성에 맞는 실행 방법과 현재 구현 범위 추가.
- `app/.gitkeep`, `steps/.gitkeep`: 실제 파일이 생성되어 빈 폴더 보존용 파일 제거.
